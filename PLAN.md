# План работ

## Найденные проблемы
1. **Условия победы**: маньяк побеждал при 2 выживших (`alive.length <= 2`), мафия считалась по паритету «со всеми остальными», город — «нет мафии и маньяка». Правила нигде не были явно показаны, в интерфейсе и в журнале расходились.
2. **Одиночные роли**: движок предполагал одного маньяка/доктора/детектива (`state.night.maniacTarget`, `find(p => p.role === 'detective')`), поэтому произвольный состав невозможен.
3. **Хост мог пропускать фазы** кнопкой «Дальше» без ограничений.
4. **Мёртвые писали в общий чат** — ограничений не было.
5. **Ночное действие** фиксировалось сразу, без подтверждения и без окна на исправление.
6. **Нет готовности в лобби**: партия стартовала сразу, любой мог начать за всех.
7. **Нет пользовательских комнат**: ни пароля, ни настроек, ни редактора ролей.
8. **Нет списка комнат и быстрого подбора**: PeerJS не умеет перечислять комнаты — нужен отдельный сервис обнаружения.
9. **Нет голосования за кик**, нет голосового чата.
10. **Роли не скрывались корректно** при нескольких экземплярах; не было роли «Шериф».

## План изменений
- `types.ts`, `roles.ts`: роль `sheriff`, `RoleComposition`, `RoomSettings`, составные ночные действия, `KickVote`, новые `Action`.
- `engine.ts`: настраиваемые условия победы, произвольный состав, пароль- agnostic лобби, готовность, ручные фазы, кик-голосование, чат мёртвых, окно подтверждения ночи, автопилот с автоготовностью.
- `view.ts`: настройки, готовность, кик-голосование, приватные проверки, фракции вместо `boolean`.
- `session.ts` + `net/peer.ts`: пароль (проверка на хосте, без утечки), каталог/подбор через отдельный сервис обнаружения, сигналинг голосового чата.
- UI: `RoomSetup`, `FindGame`, лобби с настройками/редактором ролей/готовностью, игровой экран с подтверждением ночи, голосованием за кик и микрофоном.
- `server/discovery.mjs`: отдельный сервис каталога комнат.
- Тесты: `tests/engine.test.ts` (расширение), `tests/rooms.test.ts`, `tests/i18n.test.ts`.
